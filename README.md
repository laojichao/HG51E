# HG51E - 中国移动光猫账号密码查询工具

> ⚠️ **重要提示**：本工具仅适用于 **深圳2024版本** 且 **未加密** 的固件。其他地区或版本可能已加密，无法直接获取账号密码。

## 简介

针对中国移动吉比特 HG51E 光猫的辅助工具应用。通过向光猫内置 Web 管理接口发送 HTTP 请求，自动获取宽带账号和密码信息，并支持一键复制到剪贴板。

## 工作原理

### 光猫 Web 管理接口

HG51E 光猫内置了一个 Boa Web Server，提供 CGI 接口用于管理。本应用通过以下接口获取用户信息：

```
GET http://{host}/boaform/web_query_user_show.cgi
```

**返回数据格式 (JSON)：**
```json
{
  "web_tele_account_name": "宽带账号",
  "teleAccount_password": "宽带密码"
}
```

### 请求流程

```
┌─────────────┐         HTTP GET          ┌─────────────┐
│   Android   │ ───────────────────────── │   光猫设备   │
│    App      │                           │  (Boa Web)  │
└─────────────┘                           └─────────────┘
       │                                         │
       │  1. 检测网络连接状态                      │
       │  2. 检测 VPN/代理                         │
       │  3. 发送 HTTP 请求                        │
       │                                         │
       │         返回 JSON 用户信息                │
       │ ◄────────────────────────────────────── │
       │                                         │
       │  4. 解析 JSON                             │
       │  5. 显示账号密码                          │
       │  6. 支持一键复制                          │
```

### 关键特性

1. **无需认证**：该 CGI 接口无需登录 Cookie，依赖局域网访问控制
2. **强制直连**：通过 `Proxy.NO_PROXY` 绕过系统代理，确保直连光猫
3. **网络安全**：配置了 `network_security_config` 允许明文 HTTP 通信

## 使用方法

1. 确保手机连接到光猫的 WiFi 或有线网络
2. 打开应用，默认网关地址为 `192.168.1.1`
3. 点击查询按钮获取宽带账号密码
4. 点击账号或密码可一键复制

## 注意事项

- **仅适用于深圳2024版本未加密的固件**
- 其他地区或版本可能已加密，无法获取账号密码
- 仅适用于移动吉比特 HG51E 型号光猫
- 请确保手机与光猫在同一局域网内
- 如遇问题，请检查网络连接和光猫 IP 地址

## 逆向分析要点

- **CGI 接口**：`/boaform/web_query_user_show.cgi` 是光猫内置 Boa Web Server 的 CGI 脚本
- **认证机制**：当前代码未携带认证 Cookie，说明该接口可能无需登录即可访问
- **加密差异**：不同地区固件版本可能对返回数据进行加密，需对比抓包结果确认
- **扩展方向**：同系列光猫可能存在其他 CGI 接口（如 `web_login.cgi`、`web_switch_mac.cgi`）
